## 🤖 Projects

### 🧠 Carl Jr.

One of my biggest projects has been **Carl Jr.**, a Raspberry Pi-based robot.

Carl Jr. combines hardware and software to create a remotely controlled rover with features such as:

- 🤖 Raspberry Pi-based robotics
- 🎮 Wireless control
- 📹 Live camera/video feed
- ⌨️ Keyboard-based movement
- 🧭 On-screen movement direction
- 🔌 Arduino-based inputs
- 🧠 Experimental AI and automation features

The project has gone through multiple versions as I've continued adding features and improving the system.

---

### 💡 Raspberry Pi Reaction Time Game
